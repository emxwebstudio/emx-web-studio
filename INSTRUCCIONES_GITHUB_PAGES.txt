EMX WEB STUDIO — PUBLICAR EN GITHUB PAGES
=======================================

1. Descomprime el ZIP en tu computadora.
2. En GitHub, crea un repositorio público llamado emx-web-studio.
3. Carga el CONTENIDO de la carpeta extraída, con index.html en la raíz.
4. Guarda los cambios (Commit changes).
5. Abre Settings > Pages.
6. Source: Deploy from a branch.
7. Branch: main / (root), y pulsa Save.
8. Abre la dirección que GitHub Pages genere en Settings > Pages.
